# Portofolio Pribadi Alexander Lawrensius - Tugas Akhir Praktikum Pemrograman Web (TA Percobaan 2)

Website portofolio pribadi ini dibuat menggunakan **HTML dan CSS murni (tanpa JavaScript maupun framework)**.  
Tujuan utamanya adalah untuk menampilkan profil pribadi, proyek-proyek yang pernah dikerjakan, dan informasi kontak secara interaktif dan responsif.

---

## ✨ Fitur Utama
- Navbar interaktif dengan efek hover.
- Section "Tentang" berisi foto dan deskripsi diri.
- Section "Proyek" dengan tampilan kartu animatif.
- Section "Kontak" berisi tautan sosial dan form pengiriman pesan.
- Footer dengan hak cipta.
- Efek animasi dan transisi lembut di seluruh halaman.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5**
- **CSS3 (Flexbox, Animasi, Transisi)**
- **Git & GitHub**
